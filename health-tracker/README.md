# 健康紀錄 App

免安裝、可離線使用的健康資訊紀錄網頁 App（PWA），支援全家人一起使用、服藥提醒，以及**可選擇**的端對端加密雲端同步。

## 功能

### 健康紀錄
- **10 種指標**：體重（含體脂、BMI）、血壓（含脈搏）、心率、血糖（空腹／餐前／餐後／隨機）、體溫、睡眠（時數＋品質）、飲水、步數、運動、心情
- **總覽**：每項指標的最新數值；飲水／步數／運動顯示今日累計，飲水另顯示目標達成率
- **自動判讀**：血壓分級、血糖、體溫、心率、BMI（台灣國健署標準），超出範圍會以橘色標示
- **趨勢圖**：7 天／30 天／90 天／一年；血壓同時畫收縮壓與舒張壓；體重、飲水顯示目標線
- **歷史紀錄**：依日期分組，可篩選類型（含服藥紀錄）、編輯、刪除

### 👨‍👩‍👧 多人使用
- 上方選單可切換家庭成員，每位成員有自己的紀錄、藥物、身高、目標體重與飲水目標
- 在「設定 → 家庭成員」新增、編輯、刪除成員（刪除成員會一併刪除他的資料）
- BMI 依目前成員的身高計算

### 💊 服藥提醒
- 設定藥名、劑量、每天多個服用時間、每週哪幾天、開始日期
- 「今日服藥」清單（服藥頁與總覽都有）：一鍵記錄「已服用」或「略過」，過時未服用會以橘色標示
- 顯示每種藥物近 7 天的服藥率
- **通知**：開啟通知後，到了服藥時間會跳出提醒（可直接在通知上按「已服用」）；有多位成員時通知會標示是誰要吃藥
- **匯出到行事曆（.ics）**：網頁 App 被完全關閉時無法自行跳通知，匯入手機行事曆後由系統負責提醒，最可靠

> 通知需要 App 開著或在背景執行；iPhone 需先「加入主畫面」（iOS 16.4 以上）才能使用通知。

### 🧪 檢驗報告（拍照辨識）
- 收錄約 110 個常見健檢與抽血項目，依 26 個類別整理：一般理學、血液、尿液、尿液特殊、糞便、肝功能、膽功能、腎功能、血糖、血脂肪、特殊脂肪、心血管與發炎、肝炎、尿酸、胎兒蛋白、甲狀腺、癌胚抗原、癌症指標、心電圖、胸部／腹部 X 光、腹部超音波、梅毒、肺功能、骨質密度、愛滋病、聽力、生化（電解質與營養）
- 每個項目都有單位、參考值與自動判讀（偏高／偏低／陽性…）；男女參考值不同的項目，依成員設定的生理性別判讀
- **點項目名稱或類別名稱**，會跳出臨床意義說明、參考值，以及歷次結果與趨勢
- **拍照辨識**：拍下報告（可一次選多張），在手機上辨識文字並自動對應到正確項目，同時嘗試辨識報告日期（支援民國年）
  - 辨識後會先進入「確認辨識結果」畫面，每個數值都可以修改，確認後才儲存
  - 小數點容易被漏掉（例如 1.1 被辨識成 11），數值明顯超出範圍時會提示「可能是 1.1？」，點一下即可套用
  - 辨識在裝置上進行（[Tesseract.js](https://github.com/naptha/tesseract.js)），**照片不會上傳**；第一次使用需下載約 8 MB 的辨識資料
  - 拍照建議：報告平放、光線充足、避免反光與陰影，畫面只拍表格部分效果最好
- 也可以手動輸入，並用搜尋快速找到項目
- 參考值依各醫院檢驗方法略有不同，請以報告上的參考值為準。PSA、CA-153、β-HCG、球蛋白、視力、肺功能、骨質密度等項目未提供參考值，只記錄數值不做判讀

### 💡 健康建議（每月回顧）
- 底部「建議」分頁會分析這位成員一整個月的紀錄（體重、血壓、居家血糖、睡眠、運動、步數、飲水、心情、服藥）與月底前最新的檢驗報告
- **本月概況**：與上個月比較，▲▼ 顯示變好（綠）或變差（橘）
- **飲食、睡眠、運動、追蹤** 四類建議，每則都寫出你的數據、具體做法與依據的指引，例如：
  - 血壓偏高 → 減鹽（台灣 < 2,400 mg、美國 < 2,300 mg 鈉）、得舒飲食、S-ABCDE、722 量血壓
  - LDL、三酸甘油酯、血糖、尿酸、肝功能、BMI、貧血、維生素 D、腎功能異常 → 對應的飲食調整
  - 睡眠少於 7 小時（65 歲以上 7–8 小時）或品質差 → 睡眠衛生、何時該就醫
  - 每週運動未達 150 分鐘 → 補足方式、每週 2 天肌力訓練（65 歲以上加平衡訓練）
  - 追蹤：需複檢的檢驗項目、超過 1 年沒有健檢、依年齡與性別適用的公費成人健檢與癌症篩檢、服藥率、心情低落（安心專線 1925）
- **每月提醒**：設定每月提醒日，當天打開 App 會在總覽頁顯示「上個月健康回顧已整理好」並跳通知；App 關閉時無法通知，可匯出到手機行事曆每月提醒
- 依據的指引：衛福部國健署《每日飲食指南》、成人身體活動建議、飲水與體重分級、成人預防保健與癌症篩檢；台灣高血壓學會、台灣睡眠醫學學會、台灣腎臟醫學會；美國飲食指南、NHLBI 得舒飲食、AHA、ADA、ACR、AASLD、美國身體活動指南第二版、AASM／CDC 睡眠建議
- 在「設定 → 家庭成員」填寫**性別與出生年**，建議會更準確（睡眠時數、篩檢資格）
- 建議為依規則自動整理的一般性衛教，不能取代醫師或營養師的個別評估；公費篩檢資格以國健署最新公告為準

### 🍎 匯入 Apple 與 Google 健康資料
在「設定 → 匯入 Apple 與 Google 健康資料」選擇匯出檔，匯入到目前的成員（可選最近 3 個月、1 年、3 年或全部）：

| 來源 | 怎麼匯出 | 可匯入的資料 |
| --- | --- | --- |
| **Apple「健康」** | iPhone「健康」App → 右上角頭像 → 匯出所有健康資料 → 儲存 `export.zip` | 步數、睡眠（只算睡著時間）、運動時間、靜止心率、體重、血壓、血糖、體溫、飲水 |
| **Google（Fitbit）** | [Google Takeout](https://takeout.google.com/) 勾選「Fitbit」→ 下載 `.zip` | 步數、睡眠、活動分鐘（中等＋高強度）、靜止心率、體重 |
| **Google Fit** | Google Takeout 勾選「Fit」→ 下載 `.zip` | 步數、Heart Minutes（作為運動時間）、體重、睡眠 |

- 檔案在裝置上解析（大型 `export.zip` 也是逐段讀取），**不會上傳**
- 同一天、同一種資料使用固定 id，**重複匯入只會更新、不會重複**
- iPhone 與 Apple Watch 同時計步時，每天取較大的一方；Apple 與 Google 都有同一天的步數、睡眠、運動時，也只保留較大的一筆，避免加總
- 單位自動換算：磅→公斤、mmol/L→mg/dL、°F→°C；Fitbit 體重單位可在匯入前確認
- Android 的 Health Connect 目前沒有網頁可以讀取的匯出格式；若手錶或 App 會同步到 Fitbit，可以從 Fitbit 匯出

### ☁️ 雲端備份（iCloud／Google 雲端硬碟）
- **備份到 iCloud／雲端硬碟**：產生一個包含所有成員、紀錄、藥物與檢驗報告的備份檔，透過手機的分享選單存到 iCloud 雲端硬碟（iPhone：儲存到檔案）或 Google 雲端硬碟（Android）。不需要任何設定
- **從備份檔還原**：從檔案選單打開 iCloud 雲端硬碟或 Google 雲端硬碟裡的備份檔，會與現有資料合併（較新的版本為準）
- **Google 雲端硬碟一鍵備份／還原**：存在 Google 雲端硬碟的「應用程式專用資料夾」，只有這個 App 能讀寫，會使用你的 Google One 儲存空間。需要先設定 Google OAuth 用戶端 ID（見下方）

#### 設定 Google OAuth 用戶端 ID（一次即可）
1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立一個專案（免費）
2. 「API 和服務 → 程式庫」搜尋 **Google Drive API**，按「啟用」
3. 「OAuth 同意畫面」：使用者類型選「外部」，填寫 App 名稱與聯絡信箱；在「測試使用者」加入要使用的家人 Google 帳號
4. 「憑證 → 建立憑證 → OAuth 用戶端 ID」，應用程式類型選「網頁應用程式」，在「已授權的 JavaScript 來源」加入：
   - `https://1120yg-allen.github.io`
   - （本機測試時）`http://localhost:8000`
5. 複製「用戶端 ID」（`…apps.googleusercontent.com`），任選一種方式設定：
   - 寫在 `health-tracker/config.js` 的 `googleClientId`（全家人都不用再設定）
   - 或在 App「設定 → 雲端備份 → 設定 Google OAuth 用戶端 ID」貼上（只套用在這台裝置）

App 只要求 `drive.appdata` 權限，**看不到你雲端硬碟裡的其他檔案**。

### ☁️ 資料儲存方式（可選）
在「設定 → 資料儲存方式」選擇：

| 模式 | 說明 |
| --- | --- |
| **只存在這台裝置**（預設） | 資料只在瀏覽器的 localStorage，不會傳到任何地方 |
| **雲端同步** | 多台裝置（例如全家人的手機）共用同一份資料，離線時照常使用，連線後自動同步 |

雲端同步採**端對端加密**：
- 由「同步帳號＋同步密碼」在裝置上推導出加密金鑰（PBKDF2-SHA256，31 萬次），資料以 AES-GCM 加密後才上傳
- 伺服器只保存密文與存取權杖的雜湊，看不到健康資料、也看不到帳號名稱
- 密碼不會被儲存或傳送；**忘記密碼就無法取回雲端資料**（本機資料不受影響）
- 多台裝置同時修改時會自動合併（以每筆紀錄最後修改時間為準），刪除也會同步

同步伺服器需要自己架設，見 [`../health-sync-server`](../health-sync-server/README.md)。

## 使用方式

### 最簡單：只在本機使用

```bash
cd health-tracker
python3 -m http.server 8000
```

開啟 <http://localhost:8000>。（直接雙擊 `index.html` 也能用，但離線快取、通知與雲端同步需要透過 http 伺服器開啟。）

### 搭配雲端同步

```bash
node health-sync-server/server.js
```

伺服器同時提供 App 網頁與同步 API，開啟 <http://localhost:8787> 即可使用。要讓手機連線，請部署到有 **HTTPS** 的主機（瀏覽器的加密功能只在 https 或 localhost 下可用），詳見伺服器的 README。

App 也可以放在 GitHub Pages 等靜態網站，同步伺服器放在別處；在設定中填入伺服器網址即可。

## 新增自訂指標

在 `app.js` 最上方的 `TYPES` 物件加一筆即可（檢驗項目則加在 `lab-catalog.js`），例如：

```js
spo2: {
  label: '血氧', icon: '🫁', unit: '%',
  fields: [{ key: 'spo2', label: '血氧', unit: '%', min: 70, max: 100, step: 1, required: true }],
  series: [{ key: 'spo2', label: '血氧' }],
},
```

若希望同一天的多筆紀錄加總（像飲水），加上 `aggregate: 'sum'`。

## 資料保存

- 資料存在這台裝置的 **IndexedDB** 資料庫（容量遠大於 localStorage 的約 5 MB，可存數萬筆紀錄）；舊版存在 localStorage 的資料，第一次開啟新版時會自動搬移
- 已有資料時會向瀏覽器申請**長期保存**（`navigator.storage.persist()`），空間不足時瀏覽器不會自動清除
- 修改會在 0.1 秒內寫入；切到背景或關閉頁面時會立即寫入，並另存一份緊急副本，下次開啟時合併，避免最後一筆修改遺失
- 同時開兩個分頁時，彼此的修改會合併，不會互相覆蓋
- 「設定 → 資料保存狀態」顯示儲存位置、是否受保護、已用空間與上次備份時間；超過 30 天沒備份，總覽頁會提醒
- **iPhone／iPad 請「加入主畫面」使用**：在 Safari 中，網站若 7 天沒有使用，資料可能被系統清除；從主畫面開啟則不受此限制

## 注意

- 只存在本機時，清除瀏覽器的網站資料、使用無痕模式或換裝置都會看不到原本的紀錄，請定期備份（設定 → 立即備份）。
- 數值判讀僅供參考，不能取代醫師的診斷與建議。
