# 健康紀錄 App

一個免安裝、可離線使用的健康資訊紀錄網頁 App（PWA）。所有資料只存在你自己裝置的瀏覽器中，不會上傳到任何伺服器。

## 功能

- **10 種指標**：體重（含體脂、BMI）、血壓（含脈搏）、心率、血糖（空腹／餐前／餐後／隨機）、體溫、睡眠（時數＋品質）、飲水、步數、運動、心情
- **總覽**：每項指標的最新數值；飲水／步數／運動顯示今日累計，飲水另顯示目標達成率
- **自動判讀**：血壓分級、血糖、體溫、心率、BMI（台灣國健署標準），超出範圍會以橘色標示
  > 判讀僅供參考，不能取代醫師診斷。
- **趨勢圖**：7 天／30 天／90 天／一年；血壓同時畫收縮壓與舒張壓；體重顯示目標線；累計型指標以每日長條圖呈現
- **歷史紀錄**：依日期分組，可篩選類型、編輯、刪除
- **備份**：匯出 JSON（可再匯入）、匯出 CSV（可用 Excel 開啟）
- **其他**：深色模式、手機版面、可「加到主畫面」當 App 使用、離線可用

## 使用方式

### 在電腦上直接打開

直接用瀏覽器開啟 `index.html` 即可使用（離線快取功能需透過 http 伺服器才會啟用）。

### 用本機伺服器（建議，可安裝成 App）

```bash
cd health-tracker
python3 -m http.server 8000
```

然後開啟 <http://localhost:8000>。

### 放到手機上

把 `health-tracker/` 資料夾部署到任何靜態網站服務（例如 GitHub Pages、Netlify、Cloudflare Pages），
用手機瀏覽器開啟網址後選「加入主畫面」，之後就能像一般 App 一樣離線使用。

## 檔案結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構 |
| `styles.css` | 樣式（含深色模式） |
| `app.js` | 所有邏輯：指標定義、判讀、儲存、圖表、匯入匯出 |
| `sw.js` | Service Worker，提供離線快取 |
| `manifest.json`、`icon.svg` | PWA 設定與圖示 |

## 新增自訂指標

在 `app.js` 最上方的 `TYPES` 物件加一筆即可，例如：

```js
spo2: {
  label: '血氧', icon: '🫁', unit: '%',
  fields: [{ key: 'spo2', label: '血氧', unit: '%', min: 70, max: 100, step: 1, required: true }],
  series: [{ key: 'spo2', label: '血氧' }],
},
```

若希望同一天的多筆紀錄加總（像飲水），加上 `aggregate: 'sum'`。

## 注意

資料儲存在瀏覽器的 localStorage。清除瀏覽器資料、使用無痕模式或換裝置都會看不到原本的紀錄，請定期使用「設定 → 匯出 JSON」備份。
